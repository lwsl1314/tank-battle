# 🔥 坦克大战 - Tank Battle

一个基于 HTML5 Canvas 的经典坦克大战游戏，无需任何依赖，直接用浏览器打开即可游玩！

## 🎮 在线试玩

直接在浏览器中打开 `index.html` 即可开始游戏。

## 📋 游戏特色

- ✅ **经典玩法还原** — 方向键移动，空格射击
- ✅ **关卡系统** — 消灭所有敌方坦克进入下一关，难度递增
- ✅ **多种地形** — 砖墙（可破坏）、铁墙（不可破坏）、水域
- ✅ **粒子特效** — 爆炸效果与击中反馈
- ✅ **敌方AI** — 敌人会自动追踪玩家并射击
- ✅ **生命系统** — 3条命，用完游戏结束
- ✅ **分数系统** — 消灭敌人获得分数
- ✅ **基地守护** — 保护基地不被摧毁

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| ⬆️ | 向上移动 |
| ⬇️ | 向下移动 |
| ⬅️ | 向左移动 |
| ➡️ | 向右移动 |
| 空格键 | 射击 |

## 🎯 游戏目标

1. 控制你的坦克消灭所有敌方坦克
2. 保护基地（金色★）不被敌人摧毁
3. 消灭所有敌人后进入下一关

## 🛠️ 技术栈

- HTML5 Canvas
- 原生 JavaScript (ES6+)
- 无第三方依赖
